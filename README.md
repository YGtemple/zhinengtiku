## 📖 项目简介

**智能题库与学习分析平台** 是一个面向大学生期末复习场景的智能题库系统。项目定位精准切入"老师划定考试范围 → 学生针对性刷题"的高频痛点，内置文科记忆类题库作为引流入口，以低成本技术栈快速验证商业模式。

### 核心定位

- **目标用户**：大学生（期末复习场景为主）
- **核心场景**：老师划范围 → 学生针对性练习
- **切入策略**：文科记忆类题库优先引流
- **成本控制**：前期月成本 ¥100-350，四阶段演进

## ✨ 核心特性

- **精准出题** — 根据老师划定范围，AI 生成针对性练习题
- **学习分析** — 追踪薄弱知识点，个性化推荐复习重点
- **多题型支持** — 选择题、填空题、简答题、论述题
- **AI 服务集成** — RAG 管道 + 题目生成验证流水线
- **多租户架构** — 支持学校/班级/个人多维度隔离
- **成本优先** — 每个技术选型都有前期低成本方案 + 后期升级路径

## 💰 成本优化策略

### 前期低成本方案（MVP 阶段）

| 组件 | 选型 | 月成本估算 |
|------|------|-----------|
| 应用服务器 | 1 台 2C4G 云服务器 | ¥50-100 |
| 数据库 | PostgreSQL 单机版 | 同上 |
| 缓存 | Redis 单机版 | 同上 |
| 对象存储 | 按量付费 | ¥10-30 |
| CDN | 按量付费 | ¥10-30 |
| AI 服务 | 按量调用 | ¥50-200 |
| **合计** | | **¥100-350/月** |

### 后期升级路径

- 用户量增长后 → 读写分离、分库分表
- 题库规模扩大后 → 向量数据库 + 全文检索
- 并发提升后 → 服务化拆分 + 消息队列
- 商业化后 → 多租户隔离 + 企业级 SLA

## 🎯 四阶段演进路径

### 阶段一：MVP 验证（0-3 个月）
- 核心功能：题库浏览 + 在线做题 + 基础分析
- 技术栈：单体应用 + PostgreSQL + Redis
- 目标：验证用户需求，获得首批种子用户

### 阶段二：功能完善（3-6 个月）
- 新增：AI 出题 + 个性化推荐 + 错题本
- 技术栈：拆分 AI 服务 + 引入向量数据库
- 目标：提升用户留存，建立题库壁垒

### 阶段三：商业化（6-12 个月）
- 新增：学校/班级管理 + 教师端 + 付费会员
- 技术栈：多租户架构 + 服务化拆分
- 目标：跑通商业模式，实现正向现金流

### 阶段四：生态化（12 个月+）
- 新增：开放平台 + 第三方题库接入 + LMS 集成
- 技术栈：微服务 + K8s + 云原生
- 目标：成为校园题库基础设施

## 🔒 安全与合规

### 合规标准

- **PIPL** — 中国个人信息保护法合规
- **COPPA** — 美国儿童在线隐私保护法（如有未成年用户）
- **GDPR** — 欧盟通用数据保护条例（如有海外用户）

### 数据安全

- 多租户数据隔离
- 敏感数据加密存储
- 完整审计日志
- 灾备恢复策略
- 数据生命周期管理
