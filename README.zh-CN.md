# zhinengtiku

一个刷题平台的架构文档——战略、系统设计、接口、数据库、AI 服务、安全与运维。

<sub>HTML + docx · 六份文档，各两种格式</sub>

---

## 这是什么

一套学生刷题平台的完整架构文档，写在实施之前。六个部分，每份都同时产出 HTML 页面（供阅读）和 docx（供提交）。

| 文档 | 覆盖 |
|---|---|
| 00 战略定位与产品方向 | 定位与产品方向 |
| 01 总体架构概览 / 架构设计 | 系统架构 |
| 02 API 接口设计 | 接口面 |
| 03 数据库设计 | 数据模型 |
| 04 AI 服务设计 | AI 服务层 |
| 05 安全与合规设计 | 安全与合规 |
| 06 运维与部署 | 运维与部署 |

另外还有一份圆桌评审文档——几位评审对架构的批评，和被批评的设计放在一起。

## 为什么两种格式

HTML 是拿来读的：表格、示意图、交叉引用在屏幕上都更清楚。docx 是拿来提交的。两种都留着，两类读者都不亏待。

## 说明

这是设计文档，不是运行中的系统。文中描述行为的地方，描述的是预期行为。
